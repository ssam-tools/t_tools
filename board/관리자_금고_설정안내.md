# 🛡️ 관리자 · 🔐 학교 금고 켜기 (v2.52 · 업무판 담당자가 한 번)

쌤 노트의 🛡️ 관리 화면과 🔐 금고는 학교 업무판(Apps Script)에 파일 두 개가 있어야 움직입니다.
코드에는 학교 자료나 비밀번호가 없습니다. 비밀번호는 스크립트 속성과 선생님 기기에만 있습니다.

## 1. 파일 붙여 넣기
1. 업무판 시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 **파일 +** → 스크립트 → 이름 `Admin` → 이 폴더의 `Admin.gs` 내용을 통째로 붙여 넣기
3. 이미 있는 `SchoolSet` 파일 내용을 이 폴더의 새 `SchoolSet.gs`로 **통째로 바꾸기**
4. `Code.gs`의 `doPost` 안 요청 표(`setver: () => …` 가 있는 곳)에 아래 두 줄을 더하기
   ```
   admlogin: () => admLogin_(req), admping: () => admPing_(req), admlist: () => admList_(req), admadd: () => admAdd_(req), admdel: () => admDel_(req), admlog: () => admLogGet_(req),
   vltver: () => vltVer_(req), vltget: () => vltGet_(req), vltput: () => vltPut_(req), vltwipe: () => vltWipe_(req),
   ```
5. 위쪽 함수 목록에서 `관리자_시험` → [실행] → 실행 로그에 "표 확인"이 나오면 됩니다.
6. **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포** (주소는 그대로)

## 2. 비밀번호 정하기
| 무엇 | 어디에 | 누가 알아야 하나 |
|---|---|---|
| 공용 비밀번호 `PASSWORD` | 스크립트 속성 (지금 그대로) | 모든 교직원 |
| 최고 관리자 `LIB_ADMIN` | 스크립트 속성 (지금 그대로) | 정보 담당 1명 |
| 관리자(담당자) 비밀번호 | 쌤 노트 🛡️ 관리 → 🔑 비밀번호·열쇠에서 만들기 | 그 담당자만 |
| 금고 문구 | 쌤 노트 🛡️ 관리 → 🔐 금고에서 처음 만들 때 정함 | 교직원 (쿨메신저·구두로 따로) |

- 금고 문구는 **서버 어디에도 저장되지 않습니다.** 잊으면 금고를 새로 만들어야 합니다(최고 관리자가 문구 바꾸기 → 내용 다시 넣기).
- 학기 초나 전출이 있을 때: 🛡️ 관리 → 🔑 → **금고 문구 바꾸기**. 예전 문구를 가진 기기는 더 이상 열지 못합니다.
- 문구가 새어 나갔을 때: 🛡️ 관리 → 🔑 → **🚨 긴급 잠금**. 서버의 금고가 지워지고, 모든 기기가 기억한 금고를 지우며, 모든 관리자 모드가 끝납니다.

## 2-1. 💬 의견함 (v2.54)
- 업무판 Apps Script에 **Feedback.gs** 파일이 있고, Code.gs doPost 표에 `fb2 · fbmine · fblist · fbset` 네 줄이 들어 있어야 합니다(2026-11-27 배포 버전 27에 넣음).
- 공부 Gym 건의함 시트는 기본 주소를 씁니다. 다른 시트로 바꾸려면 스크립트 속성 `GYM_SHEET`에 시트 ID를 넣고, 편집기에서 `의견함_시험`을 한 번 실행해 열기 권한을 허락하세요.
- 선생님 의견 시트('의견')에는 `답변 · id` 칸이 저절로 붙습니다. 예전 판에서 보낸 글은 id가 없어 답변이 저절로 가지 않으니(화면에 ✉ 직접 전달 표시) 쿨메신저로 전해 주세요.
- 학생 답변에도 학생 이름·개인정보는 적지 않습니다.
