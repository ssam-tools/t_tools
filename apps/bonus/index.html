나이스에서 파일 받는 방법

  1. 가산점 양식 파일 : 나이스 고입 - 고입_내신관리[중] - 항목별점수관리 - 엑셀출력
  2. 수상경력 파일 : 나이스 학급담임 - 학생부 - 학교생활기록부 - 학생부 항목별 조회 - 수상경력 - 수상경력 - 저장 - XLS data
  3. 창의적체험활동 파일 : 나이스 학급담임 - 학생부 - 학교생활기록부 - 학생부 항목별 조회 - 창의적체험활동 - 창의적체험활동 - 저장 - XLS data

파일은 .xlsx 형식이어야 합니다. .xls로 받았다면 엑셀에서 열어 .xlsx로 저장해 주세요.

적용 규칙

  1. 학년별로 항목당 0.5점, 최대 2점 (공동수상은 0.3점, 교과우수상 제외)
  2. 임원·표창장을 제외한 나머지 수상은 학년별 최대 2개(최대 1점)
  3. 임원(학급 반장·부반장, 전교 학생자치회)은 내역 맨 앞, 다음 표창장, 그다음 나머지 수상
  4. 상한을 넘으면 임원 → 표창장 → 나머지 수상 순으로 남김
  5. 내역은 수상명을 띄어쓰기 없이(쉼표 뒤만 한 칸) 적고 항목마다 점수를 괄호로 표시

파일 일치 점검

1번 파일(이 프로그램이 만든 파일)과 2번 파일(나이스에 입력한 뒤 다시 내려받은 파일 등)이 같은지 비교합니다. 서식은 무시하고 셀의 값만 비교합니다.
