# 쌤 노트 v1.0 (선생님 도구 모음)

> **v1.0 개편 요약** — 메뉴 5개(🏠 홈 · 📚 수업 · 🌱 우리 반 · 🤝 학생 · 🏫 학교) + ⋯ 설정.
> 홈 = 지금 카드(다음 수업) · 오늘 챙길 것(챙길 일·종례·할 일 한 목록) · 이번 주 · 자주 쓰는 도구.
> 메뉴 화면 = 지금 카드 · 묶음 탭 · 도구 타일(상태 한 줄), 시기(학기초·학기중·학기말)에 맞게 순서가 바뀜.
> 화면 꾸미기(테마 5 · 글꼴 4 · 글자 크기 3), 교과 팩(subjects/), 학교 드라이브 자료실·내선번호, 통합 찾기(Ctrl+K), 학생 카드, 자리 배치.

> **v1.5.0 ⚡ 빠른 지도** — 출결·상담 화면의 [⚡ 지도] 탭: 지도 종류(생활·학습·복장·휴대폰·교우관계·진로·칭찬·기타, 설정에서 바꿈)를 고르고 학생을 누르면 바로 기록(5초 되돌리기), 길게 누르면 한 줄 메모, [여러 명 묶기]로 집단 지도. 30일 안 같은 지도 3번 이상 → 첫 화면 '반복 지도 · 상담 권장', [상담일지로 자세히 쓰기]는 계기·날짜가 채워진 상담일지. 학생 카드에 이번 달 지도 횟수, 쌤비 "3번 휴대폰 지도". 저장: tt_guide_v1 의 gd.
> **v1.4.0 큰 시계** — 첫 화면 머리줄 오른쪽에 큰 시각과 "3교시 · 끝까지 30분" 진행 막대(shared/clock.js). 누르면 전체 화면 시계 + 1·3·5·10분 타이머, 24시간·초 표시는 이 기기에만(snclock_v1).
> **v1.3.1 쪽차이 구간** — 교과서 PDF 중간에 쪽이 끼어 있어도(예: 77-1·77-2쪽) 쪽-단원표에 `쪽차이 2 78쪽부터` 줄을 더 넣으면 그 쪽부터 쪽 번호가 맞습니다. 쪽차이는 음수도 됩니다(표지·차례 없이 8쪽부터 시작하는 PDF → `쪽차이 -7`).
> **v1.3 학기초 세팅 · 원본 파일 바로 넣기** — 학기초 세팅(담당자)에 학교 원본 파일을 한꺼번에 끌어다 놓으면 끝: 학생 명렬(엑셀, 반이 옆으로 늘어선 모양도) · 한글 .hwpx 교직원 명렬 · 내선번호(+좌석배치도의 담임 반·교과) · 전체 교사 주간시간표 · 학사일정. 파일은 shared/hwpx.js(TTSchoolFiles)가 기기 안에서 풀어 읽고(외부 라이브러리 없음), 표에 함께 적힌 주소·계정·비밀번호 칸은 읽어 두지 않습니다. 내선번호는 교직원 명렬(tt_staff_v1 tel · 대표번호 main)에 들어가 세팅 파일로 선생님들께 함께 가고, 업무판 '내선번호' 시트가 없어도 📞 내선번호·찾기(Ctrl+K)에 나옵니다. 예전 .hwp는 한글에서 HWPX로 저장해서 넣습니다.
> **v1.2.3 쌤비 자리** — PC(넓은 화면)는 왼쪽 메뉴 막대 '학교' 아래 큰 부엉이(눈 깜빡임·처음에 폴짝) + 위쪽 🔎 찾기 앞 단추, 창은 누른 단추 옆에 열림 · 휴대폰은 오른쪽 아래 그대로 · 단축키 **Alt+B**(왼쪽 Alt, 한/영 상태와 상관없음).
> **v1.2 🎙️ 말로 기록** — apps/voice/. 학생 상담·학부모 상담·회의·수업 관찰·할 일/종례를 ① 끝나고 말로 요약(기본) ② 실시간 받아쓰기 ③ 녹음 앱 글 붙여넣기·공유(→ 쌤 노트)로 남김. 이름·연락처를 가린 요청문(shared/mask.js)으로 AI 정리(요청문 복사 / 업무판 바로 묻기) → 상담일지·학생 기록·보관함 회의록·내 할 일·종례 바구니에 저장 → 학부모 안내 문자·누가기록·추천 사유서 초안. 소리는 저장하지 않음. 공유로 받은 글은 주소에서 떼어 내 서버·저장본에 남지 않음(sw.js).
> **v1.1 쌤비** — 오른쪽 아래 부엉이 마스코트(쌤의 비서). 누르면 🎤 말로 입력("12번 지각", "종례 내일 체육복", "결석신고서 열어") · 🔎 찾기 · ☀️ 오늘 브리핑(🔊 숫자만 읽어 주기) · ⚡ 바로 실행. 파일: shared/ssambi.js. 음성 인식은 브라우저 회사 서버를 거칠 수 있어 학생은 번호로 말하기를 권함.

학급 운영과 수업에 쓰는 선생님용 도구 모음입니다.
**학생 자료는 사용하는 기기 밖으로 나가지 않습니다.** 서버가 없고, 입력한 자료는 각자의 브라우저에만 저장됩니다.

## 새 도구를 넣는 방법

1. `apps/<이름>/index.html` 을 만듭니다. `shared/tt.css` 와 `shared/tt.js` 를 불러옵니다.
2. 명단은 `TT.roster.load()`, 우리 반은 `TT.roster.home()` 으로 가져옵니다. 도구 안에서 명단을 따로 입력받지 않습니다.
3. 자료는 `TT.store.set("tt_<도구>_v1", 값)` 으로 저장합니다. 이름이 `tt_` 로 시작해야 전체 백업에 들어갑니다.
4. `shared/tools.js` 에 한 줄 추가합니다. 메뉴(menu)·묶음(group)·시기(season)를 적으면 메뉴 화면에 자리를 잡습니다.
   교과 전용 도구는 `subjects/<교과>.js` 교과 팩의 tools 에 넣습니다.

## 학기초 세팅 (apps/setup)

담당자 1명이 학생 명렬 · 교직원 명렬(내선번호 포함) · 학사일정 · 전체 교사 시간표 · 학교 정보를 **학교 세팅 파일** 하나로 내보냅니다.
원본은 [📂 학교 원본 파일 한꺼번에 넣기]에 학생 명렬 엑셀과 한글(.hwpx) 파일들을 끌어다 놓으면 됩니다(컴시간 엑셀·붙여 넣기도 그대로 됨).
파일은 언제나 비밀 문구로 잠급니다(PBKDF2 31만 번 → AES-GCM). 다른 선생님은 불러와서 내 이름 · 내 교과 · 담임 반만 고르면 됩니다.
명렬은 기본으로 "내 수업 반 + 우리 반"만 그 기기에 넣습니다. 세팅 파일과 비밀 문구는 따로 전하고, 이 저장소에는 올리지 마세요.

## 개인정보 원칙

1. 학생 이름, 출결, 상담 내용은 브라우저 저장소(이 기기)에만 둡니다.
2. 서버로 전송하지 않고, 통계·광고·외부 글꼴 같은 외부 요청을 넣지 않습니다.
3. 파일 도구는 파일을 기기 안에서만 처리합니다.
4. **이 저장소에는 실제 학생 정보를 절대 올리지 않습니다.** 백업 파일(`*.json`)도 올리지 마세요.
5. 원본 자료는 나이스에서 내려받은 파일을 기준으로 합니다.

## 수업 자료 (GitHub에 올리지 않음)

교과서 PDF · 쪽-단원표 · 기출 그림은 저작권 자료라 이 저장소에 넣지 않습니다.
선생님 컴퓨터의 `lesson_files` 폴더(textbook · page_unit · exam)에 모아 두고,
📘 교과서·수업 모드 → ⚙ → [📂 lesson_files 폴더 고르기] 로 각 기기 브라우저에 한 번 불러옵니다.

## 개인정보 원칙 (v1.0)

- 이 저장소는 누구나 볼 수 있습니다. 학생·교사 이름, 내선번호, 업무분장, 업무판 주소·비밀번호는 넣지 않습니다.
- 학생 자료는 각 기기 브라우저에만 저장됩니다(tt_… 이름, 전체 백업에 포함). 화면 꾸미기(snlook_v1)·자리표(snseat_v1)는 이 기기에만.
- 학교 자료실 파일과 내선번호는 학교 구글 드라이브에 있고, 공용 비밀번호를 아는 기기에서만 업무판 앱스 스크립트로 읽습니다.
  앱스 스크립트 코드(드라이브자료실.gs)와 설정 안내는 이 저장소가 아니라 업무판 관리 선생님에게 따로 전달합니다.
