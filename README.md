## 새 도구를 넣는 방법

1. `apps/<이름>/index.html` 을 만듭니다. `shared/tt.css` 와 `shared/tt.js` 를 불러옵니다.
2. 명단은 `TT.roster.load()`, 우리 반은 `TT.roster.home()` 으로 가져옵니다. 도구 안에서 명단을 따로 입력받지 않습니다.
3. 자료는 `TT.store.set("tt_<도구>_v1", 값)` 으로 저장합니다. 이름이 `tt_` 로 시작해야 전체 백업에 들어갑니다.
4. `shared/tools.js` 에 한 줄 추가합니다. 메뉴(menu)·묶음(group)·시기(season)를 적으면 메뉴 화면에 자리를 잡습니다.
   교과 전용 도구는 `subjects/<교과>.js` 교과 팩의 tools 에 넣습니다.

## 학기초 세팅 (apps/setup)

담당자 1명이 학생 명렬 · 교직원 명렬(내선번호 포함) · 학사일정 · 전체 교사 시간표 · 학교 정보를 **학교 세팅 파일** 하나로 내보냅니다.
원본은 [📂 학교 원본 파일 한꺼번에 넣기]에 학생 명렬 엑셀과 한글(.hwpx) 파일들을 끌어다 놓으면 됩니다(컴시간 엑셀·붙여 넣기도 그대로 됨).
파일은 언제나 비밀 문구로 잠급니다(PBKDF2 31만 번 → AES-GCM). 다른 선생님은 불러와서 내 이름 · 내 교과 · 담임 반만 고르면 됩니다.
명렬은 기본으로 "내 수업 반 + 우리 반"만 그 기기에 넣습니다. 세팅 파일과 비밀 문구는 따로 전하고, 이 저장소에는 올리지 마세요.

## 개인정보 원칙

1. 학생 이름, 출결, 상담 내용은 브라우저 저장소(이 기기)에만 둡니다.
2. 서버로 전송하지 않고, 통계·광고·외부 글꼴 같은 외부 요청을 넣지 않습니다. (예외: 급식은 나이스 공개 포털에 학교 코드·날짜만 보내 식단을 받아 옴)
3. 파일 도구는 파일을 기기 안에서만 처리합니다.
4. **이 저장소에는 실제 학생 정보를 절대 올리지 않습니다.** 백업 파일(`*.json`)도 올리지 마세요.
5. 원본 자료는 나이스에서 내려받은 파일을 기준으로 합니다.

## 수업 자료 (GitHub에 올리지 않음)

교과서 PDF · 쪽-단원표 · 기출 그림은 저작권 자료라 이 저장소에 넣지 않습니다.
선생님 컴퓨터의 `lesson_files` 폴더(textbook · page_unit · exam)에 모아 두고,
📘 교과서·수업 모드 → ⚙ → [📂 lesson_files 폴더 고르기] 로 각 기기 브라우저에 한 번 불러옵니다.

## 개인정보 원칙 (v1.0)

- 이 저장소는 누구나 볼 수 있습니다. 학생·교사 이름, 내선번호, 업무분장, 업무판 주소·비밀번호는 넣지 않습니다.
- 학생 자료는 각 기기 브라우저에만 저장됩니다(tt_… 이름, 전체 백업에 포함). 화면 꾸미기(snlook_v1)·자리표(snseat_v1)는 이 기기에만.
- 학교 자료실 파일과 내선번호는 학교 구글 드라이브에 있고, 공용 비밀번호를 아는 기기에서만 업무판 앱스 스크립트로 읽습니다.
  앱스 스크립트 코드(드라이브자료실.gs)와 설정 안내는 이 저장소가 아니라 업무판 관리 선생님에게 따로 전달합니다.
