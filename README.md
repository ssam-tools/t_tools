# 선생님 도구 모음

학급 운영과 수업에 쓰는 선생님용 도구 모음입니다.
**학생 자료는 사용하는 기기 밖으로 나가지 않습니다.** 서버가 없고, 입력한 자료는 각자의 브라우저에만 저장됩니다.

## 폴더 구조

```
index.html              첫 화면 (도구 목록)
shared/tt.css           공통 디자인 (색·버튼·대화상자)
shared/tt.js            공통 코드 (저장, 명렬표, 파일 읽기, 백업, 알림)
shared/tools.js         도구 목록
apps/<도구>/index.html  각 도구
sw.js, manifest.*       앱 설치, 오프라인 사용
assets/                 아이콘
downloads/              내려받는 PC 프로그램 (파일 합치기 실행파일)
roster.html 등          예전 주소로 들어온 사람을 새 주소로 보내는 파일
```

빌드 과정이 없습니다. 파일을 고쳐서 그대로 올리면 반영됩니다.

## 새 도구를 넣는 방법

1. `apps/<이름>/index.html` 을 만듭니다. `shared/tt.css` 와 `shared/tt.js` 를 불러옵니다.
2. 명단은 `TT.roster.load()`, 우리 반은 `TT.roster.home()` 으로 가져옵니다. 도구 안에서 명단을 따로 입력받지 않습니다.
3. 자료는 `TT.store.set("tt_<도구>_v1", 값)` 으로 저장합니다. 이름이 `tt_` 로 시작해야 전체 백업에 들어갑니다.
4. `shared/tools.js` 에 한 줄 추가합니다.

## 개인정보 원칙

1. 학생 이름, 출결, 상담 내용은 브라우저 저장소(이 기기)에만 둡니다.
2. 서버로 전송하지 않고, 통계·광고·외부 글꼴 같은 외부 요청을 넣지 않습니다.
3. 파일 도구는 파일을 기기 안에서만 처리합니다.
4. **이 저장소에는 실제 학생 정보를 절대 올리지 않습니다.** 백업 파일(`*.json`)도 올리지 마세요.
5. 원본 자료는 나이스에서 내려받은 파일을 기준으로 합니다.
